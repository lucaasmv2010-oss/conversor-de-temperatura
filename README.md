# Conversor de Temperatura

Aplicação web desenvolvida com HTML, CSS e JavaScript para realizar conversões entre Celsius e Fahrenheit.

Este projeto faz parte da minha trilha de estudos em desenvolvimento web e foi criado com o objetivo de consolidar fundamentos de JavaScript, manipulação do DOM e interação com elementos de interface.

## Sobre o projeto

O Conversor de Temperatura permite que o usuário informe um valor, escolha o tipo de conversão e visualize o resultado diretamente na interface.

O projeto foi desenvolvido com foco em uma estrutura simples, código organizado e aplicação prática dos conceitos estudados.

## Funcionalidades

- Conversão de Celsius para Fahrenheit
- Conversão de Fahrenheit para Celsius
- Seleção do tipo de conversão
- Validação de entrada
- Exibição dinâmica do resultado
- Formatação do resultado com duas casas decimais
- Interface responsiva e de fácil utilização
